# Claudeで「AIチーム」を作るはじめてガイド｜Instagramリール特典ページ 要件定義書

## 0. アーキ構成

- 確定アーキ: #6 WEBアプリ（決定論）＝静的サイト
- 操作者: ブラウザの読者（Instagram DM／オプチャ特典まとめ経由のスマホ閲覧者）
- AI本体(プロンプトY): なし（読者が自分のClaude Codeで使うプロンプトを掲載するだけ。本ページはAIを呼ばない）
- MCP: なし / 自社DB: なし / フロントUI: あり / 動的変数: なし
- 種別: Web型（静的サイト） / 配布: マイ専用（個人GitHub・GitHub Pages。導線は「リールコメント→DM→オプチャ→特典まとめ」）

## 1. 目的と成功指標

成果目標: AI初心者の40〜50代女性が、Claude Codeで「リサーチ→分析→台本」の3人のAIチームを自分で作り、リール台本づくりを1回任せるところまで進める。

- 定量: ①当日中にチームを1つ作り終える（約30分） ②役割は3つ ③コピペの文章は3本（作る・頼む・直す）
- 定性: ①1人の助手から「チームにできる」と分かる ②難しい開発用語なしで進められる ③練習用フォルダで安全に試せる

## 2. 競合調査（2026-10-07）

- 対象: noteの「AI会社ツール使い方ガイド」（プレビュー画面）。ZIP（Googleドライブ配布）で完成品を渡し、使い方を説明する形。13名のAgent、`/instagram-reels` `/note-production` `/web-production`。要Node.js・Git・Claude Code/Codex・Claude in Chrome。ライセンス・再配布の記載なし
- ZIPは、Chromeが「危険なファイル」としてブロックしたため、**取得・実行していない**（記事の記載のみが根拠）
- 方針: ZIPは使わず、**文章（プロンプト）だけで自分で作れる形**にする。名前・文章・構成・プロンプトは転用しない（オリジナル）

## 4. 検証結果（実際に動かして確認・2026-10-07）

作業場所: 空の練習フォルダ（Claude Code 2.1.292・非対話実行）

1. ページのプロンプト①を送る → 5ファイルの内容が生成された。**`.claude` への書き込みは、確認なしでは拒否された**（許可ルールを付けても同じ）。このため、検証では全文を表示させて保存した。読者の画面では、確認の許可が出る想定（**対話画面での許可の流れは未確認**）
2. 初回の設計では、台本担当のファイルにアカウントの条件が直接書かれ、`CLAUDE.md` と二重管理になった → 「条件は `CLAUDE.md` だけ」と指示を追加
3. `/reel-team` を実行 → 3人が順に動き、`outputs/` に3ファイル保存。**同じテーマで頼むと、参考リールの一文（25文字）がそのまま入った** → 入力に「作りたいテーマ」を追加し、台本担当に「書いたあとの自己見直し（8文字以上の重なりを書き直す）」を追加
4. 別テーマで再実行 → 台本は新しいテーマで、初稿の3か所を自分で書き直して提出。私の検査では、句読点を除いた最長一致が8文字（一般的な表現・文の境目）。完全な保証ではないため、ページには「たたき台」と明記
5. プロンプト③（台本の1か所を直す）→ 指定した1行だけが変わった。直したあとは重なりの再確認をしていない（ページに明記）
- 費用の目安（非対話実行での計測）: 台本づくり1回で約0.26ドル相当。実行は約10秒。サブエージェントの利用は、会話と同じ利用枠を使う（公式）
